Demo Speaking Script (1 minute)

For the demo, as you can see on the screen, we have 2 grafana dashabords — 
On the left showing the temperature data from out IoT sensors, 
and the right showing the Kubernetes cluster metrics which display
CPU usage, pod health and etc.




[1/7] Pods — (~10s)
"Here we can see all the components running on Kubernetes 
— the gRPC server that processes incoming IoT data, Grafana for visualization, 
and a two-node PostgreSQL cluster managed by CloudNativePG for high availability."

[2/7] Services — (~5s)
"These are the Kubernetes services. Grafana is exposed via a LoadBalancer 
so we can access the dashboard externally."

[3/7] PostgreSQL HA — (~10s)
"This is our CloudNativePG cluster — two instances in a healthy state with automatic failover. 
If the primary goes down, the replica takes over with zero downtime."

[4/7] HPA — (~10s)
"The Horizontal Pod Autoscaler monitors CPU usage. 
When traffic spikes above 60%, Kubernetes automatically scales the gRPC server from 2 up to 10 pods. 
In our stress test, it scaled to 8 replicas within 30 seconds."

[5/7] MQTT Broker — (~5s)
"The MQTT broker runs on a dedicated GCE VM using a Docker container. 
This is the entry point — IoT devices publish sensor data here."

[6/7] Prometheus — (~5s)
"Prometheus collects cluster metrics — CPU, memory, pod health — which we can also view in Grafana."

[7/7] Live Data — (~15s)
"Now I'm sending live temperature data from 5 simulated sensors through the full pipeline 
— MQTT broker to Cloud Dataflow, then Pub/Sub, picked up by the gRPC server, stored in PostgreSQL, 
and visualized in Grafana in real time."

Switch to Grafana
"And here in Grafana we can see the temperature readings appearing live 
— each line represents a different sensor. 
The entire infrastructure is provisioned with Terraform as infrastructure-as-code."
