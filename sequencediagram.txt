sequenceDiagram
    autonumber
    participant Sensor as Fake Temperature Publisher
    participant MQTT as Mosquitto Broker (GCE)
    participant DF as Dataflow (Mqtt_to_PubSub)
    participant PS as Cloud Pub/Sub
    participant GRPC as gRPC Server (GKE)
    participant DB as PostgreSQL (CNPG)
    participant G as Grafana

    loop Every N seconds
        Sensor->>MQTT: Publish temperature message (MQTT)
        MQTT->>DF: Stream topic data
        DF->>PS: Write transformed message
        PS->>GRPC: Deliver subscription message
        GRPC->>DB: Insert temperature row
        DB-->>GRPC: ACK
    end

    G->>DB: Query time-series data
    DB-->>G: Return results
    G-->>G: Render dashboard panels
